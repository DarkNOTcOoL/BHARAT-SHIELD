BHARATSHIELD access page

Files to deploy: index.html, logo.png, vercel.json.
No Node, Python, npm install, or backend is needed for this page.
Open index.html locally to preview.

To preserve your friend's existing project URL:
1. Back up the source of the friend's existing Vercel project.
2. In its connected Git repository, create a folder named access-portal.
3. Upload index.html, logo.png and vercel.json into that folder and commit.
4. In that SAME Vercel project, set Root Directory to access-portal.
5. Set Framework Preset to Other. Clear old build/install command overrides;
   this folder's vercel.json uses no build/install step and output directory '.'.
6. Deploy the latest commit to Production. Keep the existing project name and
   Domains unchanged. Check the existing public URL in a private browser window.
Do not delete the Vercel project or its domain.

Open BHARATSHIELD opens https://bharatshield-hosted.vercel.app/ in a new tab.
This is an access page, not an automatic redirect or an authentication system.
The shown credentials must match the actual account on the hosted backend.
This ZIP does not create accounts or change backend passwords.

The credentials in index.html are public to every visitor, including in page
source. 'noindex' asks search engines not to index; it does not protect secrets.
The admin account has supervisor privileges. Before broad sharing, replace it
with a dedicated Officer evaluator account and update both displayed values.
Only use a synthetic evaluation database with publicly shared credentials.
