These images are fictional and are not government documents.

- `01_visa_clean.png` matches the fictional `VISA26001` registry record after loading the **v6.0 visa demo record** from the Synthetic Registry page.

Select **Visa** before OCR. v6.0 extracts visa type/class, number of entries, valid-from, duration of stay, keeps visa number separate from passport reference, and shows local stamp/seal forensic candidates. Stamp/seal analysis is not issuer authentication.
